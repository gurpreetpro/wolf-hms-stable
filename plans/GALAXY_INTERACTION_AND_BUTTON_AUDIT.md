## Appendix — Method, Top Offenders & Limits

**Detection rules** (all line-accurate, JSON twin carries the same data):
1. Class 1 parses `<Button>`, `<button>` and clickable `<Badge>` opening tags; only action-labelled controls are considered (`Add|New|Create|Record|Save|Submit|Approve|…`). A control is flagged when it has no `onClick` and is not `type="submit"`/`href`/`navigate()`, when its handler is `() => {}`, `() => null`, `console.*`, `alert()`, or `toast()`, when it sets a state that is never read anywhere else in the file (phantom), when it opens a real modal in a file with no write call (close-only), or when it carries a data-presence guard such as `disabled={!selectedAdmissionId}`.
2. Class 2 flags `<Form>`/`<form>` without `onSubmit` and submit handlers that call `preventDefault()` without any `api.*`/`axios.*`/`fetch` inside the handler body.
3. Class 3 flags `*Dashboard|*Manager|*Console|*CommandCenter` files that render action buttons with zero `POST/PUT/PATCH/DELETE`.
4. Class 4 flags JSX text nodes carrying a number + clinical/financial unit (`92 mmHg`, `37.1 °C`, `450 mL`, `Rs. 1200`), hardcoded clinical status tokens (`SIMV-PC`, `Afebrile`, `Optimal`), and literal-vs-literal ternaries (`{x ? '88' : '92'}`).
5. Class 5 flags visible text containing `/api/`, `endpoint`, `Route table` wording, `PostgreSQL`, `TODO`, `coming soon`, `not implemented`, `placeholder`, `*.js`. Clinical uses of the word "route" (drug route, delivery route, "en route") are excluded by construction.
